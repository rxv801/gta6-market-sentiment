# Incidents

One short file per incident: `YYYY-MM-DD-short-name.md`. Write one when a collector misses data or fails in a way that needed action.

## Template

```
# <title>

Date: · Status: open / resolved · Data lost: yes / no

## What happened
## Impact
## Cause
## Fix
## Follow-up
```
